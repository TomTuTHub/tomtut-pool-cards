# TomTuT Pool Cards

Sammlung illustrierter Home-Assistant-Dashboard-Cards für Pooltechnik im TomTuT-Stil —
Wärmepumpe, Poolpumpe, UV-C-Lampe, Solarabsorber, Einlaufdüse, Pool-Übersicht und Werte-Kachel.
Installation später über HACS als Dashboard-Plugin.

> ⚠️ **Im Aufbau** — noch kein Release, noch nicht für den produktiven Einsatz gedacht.
